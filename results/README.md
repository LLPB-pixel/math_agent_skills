# Generated mathematical write-ups

This directory contains the `.tex` sources and corresponding PDF write-ups
produced during the mathematical test run. The TeX files are the reproducible
source; PDFs are retained as convenient preview/release artifacts.

Auxiliary files (`.aux`, `.log`, `.out`, and page previews) are deliberately
ignored. Before publishing to GitHub, decide whether the PDFs should remain in
Git or be attached as release artifacts to keep the repository lightweight.
